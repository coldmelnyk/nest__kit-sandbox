# Порядок работы

Правило без `paths:`: действует в любой задаче.

## Перед кодом

1. Задача записана в `docs/tasks/` по шаблону `docs/tasks/_template.md`. Нет задачи — сначала она, потом код. Мелкое исправление тоже получает задачу, короткую: «Зачем», «Что сделано», «Как проверено».
2. Прочитаны правила темы: таблица «Прежде чем начать — прочитать» в `AGENTS.md`. Правило по `paths:` подгружается само, только когда агент читает подходящий файл; новый файл с нуля его не подтянет.
3. Требования и код расходятся — правы требования. О расхождении говорят владельцу проекта, а не исправляют молча.

## Во время работы

- Одна ветка — одна задача. Находка по пути — запись в «Итог» задачи и отдельная ветка, а не правка «заодно».
- Нужного правила нет, нужна новая runtime-зависимость, изменение несовместимо, проверку не пройти без отключения линта или теста — агент останавливается и спрашивает (`AGENTS.md`, «Сначала спросить»).
- Параллельная задача с кодом идёт в своём worktree; тесты с базой — на своей базе.

## Правила kit и правила проекта

- `.claude/rules/kit/` — правила kit. Их не правят: следующее обновление kit остановится на правленом файле.
- `.claude/rules/project/` — дополнения проекта. Файл дополняет тему с теми же `paths:`, что у правила kit, и может отменить пункт kit только со ссылкой на решение `Р-N` в `docs/decisions.md`.
- Блоки между `<!-- kit:begin … -->` и `<!-- kit:end … -->` в `AGENTS.md` и `CLAUDE.md` принадлежат kit. Текст проекта пишется вне их.

## Готово, когда

- проходят команды из раздела «Готово, когда» в `AGENTS.md`;
- изменение записано в `docs/` (`documentation.md`);
- в задаче заполнен «Итог»: что сделано не по плану и где это записано.

## Проверяется автоматически

- Правка `.claude/rules/kit/**`, `.claude/kit/**` и `.claude/kit.json` агентом запрещена в `.claude/settings.json`.
- Запись в `docs/` при изменении значимых категорий — `docs-check` (`documentation.md`).

## Не проверяется

- Что задача написана до кода, а не после.
- Что в ветке одна задача.
- Что агент спросил, а не решил сам.
