# Роли: время, id, случайность

Роль — сквозная сущность, через которую код получает то, что нельзя воспроизвести в тесте: текущее время, новые id, случайные значения. kit описывает, что роль гарантирует, а реализацию пишет проект. Имена и пути реализаций записаны в `.claude/kit.json`.

Если реализации пока нет, правило всё равно действует для нового кода, а реализация — задача проекта (в новом проекте — `docs/tasks/001-roles.md`).

## Время — `Clock`

- **Зачем.** Код, который сам читает часы, нельзя проверить на нужной дате, а тест с ним зависит от момента запуска.
- **Контракт.** Отдаёт текущий момент. В тестах заменяется фиксированным или управляемым значением.
- **Где.** `src/shared/clock`. Объявлен глобально: модуль получает его через конструктор.
- **Запрещено вне реализации:** `new Date()` без аргументов, `Date.now()`. Разбор даты из строки или числа (`new Date(value)`) разрешён.
- **В `domain/`** время приходит параметром: entity часов не читает (`layers.md`).
- **В тестах** время подменяется через роль, а не через подделку таймеров фреймворка тестов — для дат предметной области это запрещено.

## Идентификаторы — `Ids`

- **Зачем.** Одно место, где выбран формат id и библиотека, и предсказуемые id в тестах.
- **Контракт.** Выдаёт новый id записи. Формат — UUIDv7: id растут со временем, и индекс по ним не фрагментируется.
- **Где.** `src/shared/ids`, глобально, через конструктор.
- **Запрещено вне реализации:** `randomUUID()`, прямой импорт генераторов id.
- **Id сущности, которую создаёт клиент**, приходит в запросе — так повтор запроса не создаёт дубль.

## Случайность

- **Зачем.** Случайное значение в логике делает тест невоспроизводимым.
- **Контракт.** Нужное модулю случайное значение — одноразовый код, id сессии, разброс задержки — выдаёт внешний порт модуля: `ports/<что>.port.ts`, реализация в `infrastructure/node/` (`ports.md`).
- **Секреты** (коды, id сессий) берутся только из криптографически стойкого источника платформы, не из `Math.random()`.
- **Запрещено вне реализаций:** `Math.random()`, прямые вызовы генераторов случайных байт в `domain/` и `application/`.
- **В тестах** порт заменяется двойником с заданными значениями.

## Проверяется автоматически

- `lint-roles`: запреты выше действуют во всём `src/`, кроме путей реализаций из `kit.json`.

## Не проверяется

- Что реализация роли действительно подменяется в тестовой оснастке.
- Секрет, полученный из некриптографического источника внутри реализации порта.
