# npm

Общие правила зависимостей — `base/dependencies.md`. Здесь — детали npm.

- `package-lock.json` коммитится вместе с `package.json`.
- Блок `overrides` — только чтобы закрыть уязвимость в транзитивной зависимости. Причина — в описании PR.
- `npm audit fix --force` не запускается: он чинит уязвимость откатом на старые мажорные версии.
- `npm install <пакет>` для `dependencies` — только после согласия владельца проекта.

## Проверяется автоматически

- `knip` в CI, блокирующий: неиспользуемые зависимости, файлы и экспорты; импорт пакета, которого нет в `package.json`.
- CI: `npm audit --omit=dev --audit-level=high`.

## Не проверяется

- Причина у каждого `overrides`.
